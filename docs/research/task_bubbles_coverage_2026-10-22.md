## 新增来源

1. **原角色为空的文字：23 条。** 旧索引要求存在 `TALK_ROLE_*` 类型，漏掉了有明确正文、但原角色为空的记录。现在采用已有样本文字核验出的正文 hash 字段识别记录；气泡实际 NPC 仍来自接口参数。例如 `GlobalDialog` 的 200080501 明确对应「救，救命啊！」，原角色只有空 id，没有 type；任务 20001 的两个步骤分别绑定 NPC 140301。未做 XOR 或近似编号修补。
2. **任务共享配置：15 条。** `16190.luac:0_3` 明确把 ShareConfig 的 `quest_data` 包装为 `self.shareData.QuestData`。`23982.luac` 明确声明 `main_id = 398`，提供按步骤与数组位置引用的 NPC 表；`16127.luac:0_0` 从表中捕获 NPC，`0_5` 发出气泡调用。新增解析只接纳无调用、分支、循环或子函数的常量模块；重复任务编号不合并。能恢复 NPC 但缺少正文的 3980305 仍跳过。
3. **初始化全局变量：12 条。** 20007/20017/20018 使用 `q…Cfg.NPCData.NpcID`；11100 将 Crowd 配置写入模块全局后读取 ID。现在为气泡单独保留无条件初始化值，actor 之间隔离，扫描运行时写入并将可改写变量视为未知；带分支的初始化不作为确定值。

共享配置与初始化变量恢复仅用于气泡分析，原旁白使用原来的分析实例。

按正式筛选顺序分类，366 = 236 + 96 + 1 + 33：

| 原因 | 显示候选数 | 已核对情况 |

| 文本记录缺失 | 96 | 对应 58 个明确文字 ID；遍历当前全部 Talk 命名空间与 DialogExcel，未找到同 ID 记录。不是简单的 TextMap hash 找不到 |
| NPC 参数仍不确定 | 1 | 任务 20043，`15352.luac:0_5:15` 把 `GetQuestNpcActor(...)` 返回对象传给创建接口；不能直接当作整数 NPC ID，也未改成猜测的编号 |
| 当前任务目录未收录 | 33 | 归属 15 个任务编号；其中 5 条能完整解析文字。19048 有四条环境台词；72109 有一条带 `$UNRELEASED` 标记。未为提高比例擅自增加任务目录 |

未发现单纯步骤映射丢失，也未出现同 ID 可解析内容冲突。上述原因按优先级互斥分类；例如未收录任务也可能同时缺文字。

这不是全游戏气泡覆盖率。区域 TriggerIn、其他原生回调等尚未纳入本批生命周期分母。后续更有价值的工作是核查缺失 ID 是否存在于其他版本资源、核对未收录任务，以及建立区域触发的明确事件模型。
